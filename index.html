2. Question Types and Controls

Option controls explicitly indicate the answer requirements:

  • Single Correct / True-False: Circular radio button. Choosing one option deselects other choices.
  • Match-the-Following: Two-column table (Column A items P-S matched to Column B items 1-4) followed by single-choice radio options listing the full pair sets (e.g., P-2, Q-1, R-3, S-4).
