# NPTEL Soft Skills: 100 High-Probability Exam Questions

*Weeks 1-12 | 56 single-answer, 25 multiple-answer, 19 true/false | Answer key at the end*

## How to take this test

Set a 60-minute timer and answer without notes. Single-answer questions have one correct option. For multiple-answer questions, select all correct options. Score 1 mark per question, and give credit for a multiple-answer question only if every correct option is chosen and no wrong one. Questions are built from your graded assignment topics (Weeks 1-11) plus standard course content, so recheck anything you miss in the lecture.
