# NPTEL Soft Skills: Practice Set 3 (100 Questions)

*Weeks 1-12 | 45 single-answer, 24 multiple-answer, 13 true/false, 18 match-the-following | Answer key at the end*

## How to take this test

This set uses new questions that do not repeat Set 1 or Set 2. It leans more on standard course concepts than on your graded assignment items, so if an answer surprises you, confirm it in the lecture. Set a 60-90 minute timer and answer without notes. Single-answer questions have one correct option. For multiple-answer questions, select all correct options. For match-the-following, choose the option where all four pairs are right. Score 1 mark per question, with full credit only for a fully correct answer.
