# NPTEL Soft Skills: Practice Set 2 (100 Questions with Match-the-Following)

*Weeks 1-12 | 37 single-answer, 23 multiple-answer, 25 true/false, 15 match-the-following | Answer key at the end*

## How to take this test

This set is different from Set 1: new facts, plus 15 match-the-following questions in the NPTEL style (Column A items P-S matched to Column B items 1-4). Set a 60-90 minute timer and answer without notes. Single-answer questions have one correct option. For multiple-answer questions, select all correct options. For match-the-following, choose the option where all four pairs are right. Score 1 mark per question, with full credit only for a fully correct answer. Questions follow your graded assignment topics (Weeks 1-11) plus standard course content, so recheck anything you miss in the lecture.
